# Zoom Clone

## About

Zoom Clone is a video conferencing application that allows users to create and join video calls.

## Features

- Create video calls
- Join video calls
- Screen sharing
- Chat
- Recording

## Tech Stack

- React
- Vite
- Node.js
- Express
- MongoDB
- Socket.io

## Installation

```bash
# Clone the repository
git clone https://github.com/thisisjaypatil8/Zoom-Clone.git

# Navigate to the frontend directory
cd Zoom-Clone/frontend

# Install dependencies
npm install

# Run the application
npm run dev
```
